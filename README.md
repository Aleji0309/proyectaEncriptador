- **Netlify** – Deployment and hosting

## 📋 Project Description

This application allows users to:

- Enter a message  
- Encrypt it using a custom replacement cipher  
- Decrypt it back to the original message  
- Copy the encrypted or decrypted message to the clipboard

The encryption method uses simple string substitutions, making it a fun project for beginners to practice working with strings, events, and UI feedback.

## 📌 Key Features

- Encrypts and decrypts based on custom logic  
- Real-time message handling  
- Input validation (lowercase letters and no accents)  
- Copy to clipboard functionality  
- Fully responsive layout

2. Navigate to the folder:

```bash

```

3. Open `index.html` in your browser.
