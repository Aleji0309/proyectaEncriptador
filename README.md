# Text Encryptor - Alura LATAM Challenge  

## Description  
This project was developed as part of an **Alura LATAM challenge**. It is a simple text encryptor and decryptor built using **HTML, CSS, and JavaScript**.  

The application allows users to input text, encrypt it following specific rules, and later decrypt it to retrieve the original message. This project was an excellent opportunity to apply JavaScript logic, DOM manipulation, and CSS styling.
